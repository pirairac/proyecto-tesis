
# Análisis de concordancia entre EEG y resonancia magnética

Proyecto de análisis exploratorio y estadístico de resultados de electroencefalograma (EEG) y resonancia magnética cerebral (RM) en una cohorte pediátrica.

## Objetivo

Describir los resultados de ambos exámenes y evaluar su concordancia mediante estadísticas descriptivas y pruebas de acuerdo.

## Contenido

- Caracterización de la cohorte por edad y sexo.
- Distribución de resultados normales y alterados de EEG y RM.
- Resumen de localizaciones registradas en exámenes alterados.
- Tabla de concordancia 2×2, porcentaje de acuerdo y Kappa de Cohen.
- Visualizaciones y análisis complementarios.

## Tecnologías

Python · Jupyter Notebook · pandas · NumPy · Matplotlib

## Ejecución

Abrir `notebook_base.ipynb` en Jupyter o VS Code y configurar la ruta del archivo Excel de entrada en la primera celda.

El archivo de datos no está incluido en este repositorio.
